# VERSOS Visualizer - Verificação e Extração de Ruídos de Sinais de Origem Solar

[ 🇧🇷 ] Repositório com o programa de mestrado responsável por auxiliar na pesquisa e validação de algoritmos para a automatização da extração de ruídos instrumentais e a detecção de eventos solares (flares) presentes nos atuais dados do radiotelescópio POEMAS.

[ 🇺🇸 ] Repository with the master's program designed to support the research and validation of algorithms for automating the extraction of instrumental noise and the detection of solar events (flares) in the current data from the POEMAS radiotelescope.

## Preparing the enviroment 

[ 🇧🇷 ] As bibliotecas utilizadas no projeto estão dentro do arquivo `requirements.txt`. Para instalá-las, entre no prompt de comando (cmd) dentro da pasta e digite o comando:

`pip install -r requirements.txt -user`

[ 🇺🇸 ] The libraries used in the project are listed in the `requirements.txt` file. To install them, open the command prompt (cmd) inside the project folder and run:

`pip install -r requirements.txt -user`
